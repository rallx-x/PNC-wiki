프로필
고르면 작중 행적 항목이 「메인 스토리」 또는 「전속 스토리」 아래로 묶여요. 둘 다 아니면 「선택 안 함」.
개요
문서 「1. 개요」 맨 위에 나와요. 이미지가 있으면 이미지가, 없으면 유튜브 영상 썸네일(누르면 유튜브로 이동)이 나와요. 둘 다 비우면 생략돼요.
성능
글 꾸미기 · 레벨 자동 적용 안내 (스킬·평가 칸에서 쓸 수 있어요)
레벨 효과 자동 적용

1레벨 효과만 쓰고, 레벨마다 바뀌는 숫자를 중괄호 { } 안에 숫자나 범위로 적으면 레벨에 따라 자동으로 들어가요. 바뀌는 숫자는 문서에서 굵게 나와요.

{60~105}처음과 끝만 쓰면 사이는 고르게 늘어나요 → 60, 65, 70 … 105
{60+5}레벨마다 5씩 늘어나요 → 60, 65, 70 …
{60,63.6,67.2,…,105}레벨별 숫자를 직접 적어요 (정확한 수치를 알 때). 모자라면 마지막 숫자가 이어져요

예) 일반공격 대신 충전하여 1초마다 에너지를 {60~105}점 모으며 대상에게 *연산량 3% 순수피해*를 준다.
→ Lv.1 「에너지를 60점」 … Lv.10 「에너지를 105점」

한 문장에 여러 개 써도 돼요. 만들어진 레벨 중 문장이 다른 레벨이 있으면 미리보기에서 「직접 고치기」로 그 레벨만 고칠 수 있어요. 「자동으로」를 누르면 다시 자동 글로 돌아가요.
